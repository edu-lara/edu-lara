### [TXT Color](https://github.com/VoceCertificado/txtcolor)

An extension that adds syntax highlighting, visual severity identification, and code folding to plain-text and configuration files.

[Open VSX](https://open-vsx.org/extension/VoceCertificado/txt-color) · [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=VoceCertificado.txt-color)

### [Priority Compass AI](https://github.com/edu-lara/priority-compass-ai)

An Eisenhower Matrix application that uses artificial intelligence to classify tasks and recommend an execution order. Built with Amazon Bedrock, AWS Lambda, Amazon API Gateway, and AWS Amplify.

### [Strands Agents AWS Audit](https://github.com/VoceCertificado/strands-agents-auditoria-aws)

An educational project that uses Strands Agents and Amazon Bedrock to query resources in an AWS account, organize the results, and support an inventory audit.
