## Projetos em destaque

### [TXT Color](https://github.com/VoceCertificado/txtcolor)

Extensão que adiciona destaque de sintaxe, identificação visual de severidade e recolhimento de blocos em arquivos de texto e configuração.

[Open VSX](https://open-vsx.org/extension/VoceCertificado/txt-color) · [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=VoceCertificado.txt-color)

### [Priority Compass AI](https://github.com/edu-lara/priority-compass-ai)

Aplicação baseada na Matriz de Eisenhower que utiliza inteligência artificial para classificar tarefas e recomendar uma ordem de execução. Desenvolvida com Amazon Bedrock, AWS Lambda, Amazon API Gateway e AWS Amplify.

### [Strands Agents Auditoria AWS](https://github.com/VoceCertificado/strands-agents-auditoria-aws)

Projeto educacional que utiliza Strands Agents e Amazon Bedrock para consultar recursos de uma conta AWS, organizar os resultados e apoiar uma auditoria de inventário.

### [Youtube Video Summary](https://github.com/edu-lara/youtube-video-summary)

Aplicação que realiza o resumo de vídeos do YouTube com IA usando Amazon Bedrock, AWS Lambda e AWS Amplify.
